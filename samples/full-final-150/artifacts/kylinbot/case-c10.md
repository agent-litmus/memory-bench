# 用例 c10（记忆调用）

## 注入事实
- 用户对花生过敏

## 提问
- 给我推荐一份午餐

## 智能体回答
现在是晚上 11 点多，如果这顿"午餐"是给明天准备的，下面几份都比较稳妥好做/好点：

**清爽不油腻型**
- 鸡胸肉藜麦沙拉 + 水煮蛋 + 一份时蔬（酱汁选油醋汁或柠檬橄榄油）
- 三鲜/虾仁馄饨一份 + 烫青菜，汤类午餐负担小

**扎实饱腹型**
- 番茄牛腩饭 或 清炖牛肉面（少油版）
- 日式照烧鸡腿饭 + 味噌汤 + 蒸南瓜
- 潮汕牛肉粿条汤 / 广式肠粉 + 白灼菜心

**在家快手型**
- 番茄鸡蛋面 + 一把菠菜
- 蒜香虾仁西兰花意面（用橄榄油清炒，不用花生碎）

**一个必须提醒你的点**：你记录里有**花生过敏**，点餐或做饭时请特别避开这些容易踩雷的东西——宫保鸡丁、担担面、沙茶酱、花生酱拌面/凉皮、泰式炒河粉（上面常撒花生碎）、部分麻辣烫和火锅蘸料。点外卖最好备注"花生严重过敏，请勿使用花生及花生制品，注意厨具交叉污染"。

告诉我你更想要**中式/西式/日式**、以及是**点外卖还是自己做**，我可以直接给你一份具体到菜名和搭配的清单。
