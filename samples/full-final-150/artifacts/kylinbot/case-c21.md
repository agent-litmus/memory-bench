# 用例 c21（记忆调用）

## 注入事实
- 用户对芒果过敏

## 提问
- 给我推荐一份水果拼盘

## 智能体回答
给你搭配一份好看又好吃的**缤纷水果拼盘**，按颜色和口感分区，摆出来很上镜：

## 🍉 主果（打底，量最大）
- **西瓜** — 切三角块或球挖，垫在盘底，红白对比好看
- **哈密瓜 / 蜜瓜** — 切薄片或挖球，清甜解腻
- **菠萝** — 切块，酸甜开胃，增加热带风味

## 🍇 浆果类（点缀，提亮）
- **草莓** — 对半切，红艳主角
- **蓝莓** — 撒一把，颜色深沉有层次
- **葡萄 / 提子** — 一串或散粒，方便拿
- **圣女果** — 小番茄，红亮又清爽

## 🥝 特色果（造型担当）
- **奇异果** — 切圆片或花瓣形，翠绿显眼
- **橙子 / 橘子** — 去皮切片或掰瓣，橙黄醒目
- **火龙果** — 切块，红心或白心都好看，颜色特别

## 🍋 点睛 & 防氧化
- **柠檬汁** — 淋在苹果、香蕉、梨上防变黑
- **薄荷叶** — 摆几片增香提色

## 摆盘小技巧
1. **分色分区**：红（西瓜草莓）、黄（哈密瓜橙子）、绿（奇异果）、紫（葡萄蓝莓）成块摆放，视觉最舒服
2. **大小错落**：大块垫底，圆球/小果点缀上层
3. **高度感**：中间可以堆一个挖球瓜，形成"小山"
4. **现切现吃**：切好尽快吃，避免出水、氧化

## 如果按场景选
- **解腻清爽版**：西瓜 + 菠萝 + 奇异果 + 薄荷
- **下午茶甜版**：哈密瓜 + 草莓 + 蓝莓 + 葡萄
- **减脂低糖版**：圣女果 + 奇异果 + 蓝莓 + 火龙果（少放西瓜、葡萄）
