# 用例 c11（记忆调用）

## 注入事实
- 用户偏好本地工具，不使用任何需要联网的云服务

## 提问
- 推荐一个笔记工具

## 智能体回答
推荐笔记工具要看你的使用场景，下面按需求分类：

**最省心、全平台同步**
- **Obsidian** — 本地 Markdown 文件存储（数据完全归你），插件生态极其丰富，双链笔记适合做知识管理。缺点是移动端同步需付费或自建。
- **Notion** — 数据库、看板、协作全能，适合团队和个人一体化管理。缺点是需要联网、导出数据略麻烦。

**轻量快速**
- **Apple Notes（备忘录）** — 苹果生态里最无脑好用，随手记、扫描、协作都顺滑。
- **Simplenote** — 极简纯文本，免费全平台同步，适合只想要「打开就能写」的人。

**手写 / 手绘**
- **GoodNotes / Notability** — iPad 手写笔记首选。
- **Logseq** — 大纲式 + 双链，适合每天流水式记录再慢慢整理。

**如果你是开发者**
- **Obsidian + Git 插件**，或直接用 **VS Code + Markdown**，配合笔记目录版本控制，最自由。
- **Joplin** — 开源、端到端加密、支持自建同步，隐私敏感型用户的稳妥选择。

**一句话选择建议：**
- 想要数据自主 + 强大双链 → **Obsidian**
- 想全平台零配置 + 团队协作 → **Notion**
- 只想要极简快速 → **Simplenote** 或系统自带的备忘录

如果你告诉我你的平台（Mac/Windows/手机）、是否团队协作、以及是否在意数据隐私，我可以帮你锁定一个最合适的。
