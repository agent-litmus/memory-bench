# 制造业质检员 ·岗位分析（v4）

## 一、岗位定位：质量链条上的“守门人”

质检员是制造企业质量防火墙的最前线，按生产环节分四个典型位置：

|环节 |常见叫法 |核心工作 | 关键挑战 |
|------|---------|---------|---------|
| 来料 | IQC |供应商来料抽检、让步接收判定、供应商质量反馈 |批量大，判定依据是图纸 +抽样标准 |
| 过程 | IPQC/巡检 |首件检验、定时巡检、制程异常拦截、SOP符合性核查 | 与产线实时博弈，要求反应快 |
| 成品 | FQC/OQC | 成品全检或抽检、出货前最终判定 |责任最重，漏检直接流出客户端 |
|辅助 | — | 不良品隔离标识、检验记录、数据统计上报 |琐碎，但决定数据可信度 |

**岗位本质**：入门门槛适中，责任重大。漏检放行一批不良，损失远超检验成本；误判错杀良品，又造成停线浪费。“判断准确”和“敢于说不”是这个岗位的核心价值。

**典型一天**（以 IPQC 为例）：早会了解排产 →首件检验确认后才允许批量开工 → 每1~2 小时巡检关键工序 → 异常立即开单拦截 → 下班前填检验记录、汇总当日不良数据。

## 二、能力模型**硬技能（决定下限）**
- **量具使用**：卡尺、千分尺、高度规、塞规是基本功；投影仪、三坐标（CMM）是加分项- **抽样标准**：GB/T2828.1（等效 ISO2859）的 AQL判定——质检员的“通用语言”，要熟练到不用查表- **图纸识读**：形位公差（GD&T）、表面粗糙度、基准理解- **记录与统计**：Excel透视表、合格率/直通率（FTY）计算；进阶是 SPC控制图、Minitab**软技能（决定上限）**
- **原则性与沟通的平衡**：对产线说“不”的方式，直接决定判定能否被真正执行- **异常敏感度**：从数据波动中提前发现趋势性劣化，而不是等不良爆发- **闭环意识**：发现问题 → 上报 →跟踪改善 →验证效果，不闭环不算完成## 三、岗位自评清单（沿用 v3，仍未反馈可先自测）

每项符合得1 分：①常用量具独立熟练使用② 不查表说出常用 AQL（1.0/1.5/2.5）抽样数与判定数③独立识读形位公差与粗糙度标注④ 会用透视表做不良统计和柏拉图⑤独立写完整异常单/检验日报⑥参与过8D 或改善项目⑦ 会画并解读 SPC控制图⑧ 了解 ISO9001检验相关条款（如8.6放行）⑨ 能对供应商/产线做质量技术沟通⑩ 会用 FMEA/MSA 至少一种- **1~4 分（执行层）**：先把1~4补齐，这是不可替代的基本盘- **5~7 分（骨干层）**：已具备向 QE/SQE转型资格，缺体系知识和改善项目经历- **8~10 分（准工程师层）**：该主动争取升职或跳槽了，市场会给您定价## 四、高频实战场景应对（v4 新增）

这是前三版没有展开、但实际工作中最容易“踩坑”的部分：

|场景 |错误做法 |建议做法 |
|------|---------|---------|
| **产线催放行**：“订单急，先放后补检” | 直接顶回去或默默妥协 | 按“特采/紧急放行流程”走：让生产部走书面申请 + 上级批准，自己不私自担责，留痕 |
| **临界值判定**：测出9.98，公差10±0.05（下限9.95）内但接近极限 |凭感觉放行 |按标准判合格，但加密复测频次并记录，趋势恶化时提前预警——这就是“异常敏感度” |
| **供应商不配合**：来料不良，供应商说是使用不当 | 来回扯皮 |拍照+留样+检测数据三件套固定证据，按合同/图纸条款出书面联络单，升级到 SQE 或采购 |
| **被判“误杀”**：产线说你错判良品为不良 |僵持 |首先复核自己的量具和方法（MSA意识），确认无误后用数据沟通；确属自己错判要大方承认并复盘 |
| **写异常单没人理** | 只口头说 | 异常单写清“现象-数据-影响-建议”四要素，抄送双方主管；口头说一百遍不如书面留一单 |

**共性原则**：一切以**书面+数据**为准，既保护产品，也保护自己。

## 五、行业趋势（精简保留）
