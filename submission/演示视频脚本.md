# 演示视频逐镜头脚本

> 目标：openKylin 桌面环境下，针对 **≥2 款不同智能体** 运行评测，产出**多维对比雷达图**。
> 时长建议 **3–5 分钟**；分辨率 1080p；使用系统自带录屏或 `ffmpeg`/`kylin-recorder`；旁白清晰、关键信息配字幕。
> 说明：若演示机未安装 KylinBot/Hermes，可用随包预置证据（`samples/`）与内置确定性智能体（`--include-builtin`）完整演示，无需联网或外部服务。

---

## Shot 1（0:00–0:25）开场与环境

- **画面**：openKylin 桌面全景 → 打开终端。
- **旁白**：介绍 openKylin 生态与“智能体长期记忆难以量化评测”的痛点，点出本项目定位：黑盒、可解释、可复现的记忆评测基准。
- **字幕**：面向 openKylin 的智能体长期记忆自动化评测 Benchmark。

## Shot 2（0:25–0:45）一键 CLI

- **操作**：`java -jar memory-bench.jar --help`
- **画面**：展示命令帮助，说明零依赖核心、一键运行。
- **旁白**：工具已封装为 CLI（并提供 .deb），无需配置即可运行核心评测。

## Shot 3（0:45–1:10）多智能体配置

- **操作**：`cat examples/agents-multi.json`
- **画面**：展示两个真实智能体配置——KylinBot（CLI 适配器）与 Hermes（ACP 适配器）。
- **旁白**：支持通过 `--agents-config` 导入不同智能体配置，做批量对比评测；也能接外部 HTTP 服务。

## Shot 4（1:10–2:10）运行评测

- **操作**：`java -jar memory-bench.jar run --agents-config examples/agents-multi.json --include-builtin --out out-multi-final`
- **画面**：滚动日志展示用例执行、证据采集过程（可加速播放）。
- **旁白**：对两个真实智能体 + 内置标定智能体统一跑 150 条六维用例，全程自动、零人工评分。

## Shot 5（2:10–2:40）可解释结果

- **操作**：`cat out-multi-final/report.txt`
- **画面**：展示六维通过率，以及每条用例的**五分类归因**（正确记忆 / 遗漏 / 混淆 / 错误持久化 / 错误复用）与原因。
- **旁白**：评分不是只给总分，而是区分五种失败模式并给出可解释原因。

## Shot 6（2:40–3:10）多维雷达对比

- **操作**：浏览器打开 `out-multi-final/report.html`
- **画面**：KylinBot vs Hermes 的**六维雷达对比图**。
- **旁白**：一眼看出两款智能体在“相近区分”“边界识别”等维度的差异。

## Shot 7（3:10–3:30）真实系统预置证据

- **操作**：`ls samples/ && cat samples/hermes-final/report.txt`
- **画面**：展示随包提供的真实智能体运行证据。
- **旁白**：KylinBot/Hermes 是真实系统跑出的结果，以预置证据形式提供，评委无需复跑即可核验。

## Shot 8（3:30–4:10）离线可复现与评分器标定

- **操作**：`java -jar memory-bench.jar run --agents-config examples/agents-builtin.json --out out-builtin`
- **画面**：reference 智能体 = 100%、degraded 智能体 = **54%**（其中动态更新 0%、边界识别 0%），重复运行 σ=0。
- **旁白**：内置确定性智能体既标定评分链路正确性，又保证核心 benchmark 离线、零依赖、可复现。

## Shot 9（4:10–4:40）数据集可扩展

- **操作**：`java -jar memory-bench.jar export-cases -o my-cases.json && head my-cases.json`
- **画面**：展示用例 JSON 结构。
- **旁白**：150 条例外置为 JSON，可增补样本、扩展记忆类型，体现可扩展性。

## Shot 10（4:40–5:00）收尾点题

- **画面**：回到雷达图 + 项目目录。
- **旁白**：本基准以“黑盒 + 可解释归因 + 可复现”服务 openKylin 社区智能体能力的持续评估与优化。

---

## 拍摄提示

- 终端字体调大、配色高对比，确保录屏可读；
- Shot 4 日志较长，可 2–4 倍速播放并保留首尾；
- 若现场真装了 KylinBot/Hermes，Shot 4 直接跑真实智能体更有说服力；否则用 Shot 7/8 的预置证据与内置智能体兜底；
- 关键数字（100% / 54%、六维、五分类）用字幕强化。
